# 툭(Tuk) 플래너

툭 던지면 알아서 정리되는 AI 일정·할 일 관리 웹앱입니다.

회의와 미팅이 많아지면 일정 관리가 중요해지지만, 캘린더 앱은 칸을 하나씩 채우는 게 귀찮고 노션은 익히기 어렵습니다. 툭 플래너는 **입력과 정리를 대신 해 주는 것**에 집중했습니다.

- 사용해 보기: https://gaogang1011.github.io/tuk-planner/
- 문서: [PRD](PRD.md) · [Todo 리스트](TODO.md)

## 주요 기능

| 기능 | 설명 |
|---|---|
| 한 줄 빠른 입력 | `다음 주 화요일 3시 교수님 면담, 그 전에 자료 정리`처럼 말하듯 쓰면 일정 1개와 할 일 1개로 나눠 줍니다. 추가 전에 미리보기에서 종류·제목·시간을 고칠 수 있습니다. |
| 회의 메모 → 할 일 | 회의 메모를 붙여 넣으면 할 일과 다음 일정만 뽑습니다. `준혁: API 문서 정리`처럼 다른 사람이 맡은 일은 체크를 풀어 둡니다. |
| 지금 / 다음 화면 | 다음 일정까지 남은 시간을 크게 보여 주고, 오늘 하루를 리본으로 그려 일정과 빈 시간을 한눈에 보여 줍니다. |
| 빈 시간에 할 일 | 지금부터 다음 일정까지 비는 시간을 계산하고, 마감이 급한 순서로 할 일을 추천합니다. |
| 오늘 브리핑 | 남은 일정, 마감, 쓸 만한 빈 시간을 2~3문장으로 요약합니다. |
| 목록 관리 | 날짜별 타임라인, 완료 체크, 수정, 삭제, 직접 추가 |

## AI 연결 (선택)

AI 없이도 **규칙 기반 한국어 파서**로 모든 기능이 동작합니다. AI를 연결하면 더 자유로운 문장과 복잡한 회의 메모도 이해합니다.

1. 오른쪽 위 **설정**을 누릅니다.
2. AI 서비스로 Google Gemini 또는 Anthropic Claude를 고르고 API 키를 붙여 넣습니다.
3. **연결 확인**으로 동작을 확인한 뒤 저장합니다.

API 키는 사용하는 브라우저의 localStorage에만 저장되고, 이 저장소나 다른 서버로 올라가지 않습니다. AI 호출이 실패하면 자동으로 규칙 기반 파서로 대신 정리합니다.

## 규칙 기반 파서가 알아듣는 표현

- 날짜: 오늘, 내일, 모레, 글피, ○요일, 목욜, 이번 주/다음 주/다다음 주 ○요일, 주말, ○월 ○일, 10/20, ○일 뒤, ○주 뒤
- 시간: 3시, 3시 반, 3시 20분, 14:30, 오전/오후/아침/점심/저녁/밤, 세시·여섯시 같은 한글 숫자, 정오
- 범위·길이: 10시부터 12시까지, 2시-3시, 1시간, 1시간 반
- 관계: "그 전에"는 앞 일정 시작을 마감으로, "끝나고"는 그날 안으로
- 오전/오후 없이 1~7시는 오후로 봅니다.

## 실행

설치나 빌드가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다.

## 테스트

```bash
node tests/parser.test.js
```

예시 문장 15개와 회의 메모 1개로 파서 결과를 확인합니다.

## 구조

```
index.html          화면 뼈대
css/style.css       디자인 (라이트/다크 모드, 모바일 대응)
js/format.js        날짜 표시 도우미
js/store.js         일정·할 일 데이터와 localStorage 저장
js/parser.js        규칙 기반 한국어 날짜·시간 파서, 회의 메모 추출
js/ai.js            Gemini/Claude 호출 (자연어 파싱, 메모 추출, 브리핑)
js/settings.js      설정 화면
js/capture.js       한 줄 입력·회의 메모 입력과 미리보기
js/now.js           지금/다음 카드, 하루 리본, 빈 시간·추천·브리핑
js/views.js         날짜별 목록, 수정·삭제
js/app.js           화면 연결
tests/              파서 테스트
```

## 만든 방법

인공지능 프로그래밍 수업의 바이브 코딩 과제로, AI와 대화하며 만들었습니다. PRD와 Todo 리스트를 먼저 작성하고, Todo 항목 하나를 끝낼 때마다 체크하고 커밋·push했습니다. 커밋 기록에서 진행 순서를 확인할 수 있습니다.
