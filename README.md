# 툭(Tuk) 플래너

툭 던지면 알아서 정리되는 AI 일정·할 일 관리 웹앱입니다.

회의와 미팅이 많아지면 일정 관리가 중요해지지만, 캘린더 앱은 칸을 하나씩 채우는 게 귀찮고 노션은 익히기 어렵습니다. 툭 플래너는 **입력과 정리를 대신 해 주고**, 노션처럼 **한 화면에서** 캘린더와 할 일을 함께 보며, 다른 프로그램을 쓰는 중에도 **화면 위에 떠 있는 위젯**으로 오늘 일정을 확인할 수 있게 만들었습니다.

- 사용해 보기: https://gaogang1011.github.io/tuk-planner/
- 문서: [PRD](PRD.md) · [Todo 리스트](TODO.md) · [2차 조사](docs/research.md) · [3차 조사](docs/research-3.md)

## 한 화면 구성

```
┌ 사이드바 ─────┬ 가운데 ──────────────────────┬ 오늘 패널 ──────┐
│ 검색·추가 ⌘K  │ 기간 ‹ 오늘 ›   [일|주|월]     │ 지금 / 다음      │
│ 미니 달력     │ [ 툭 던져 두세요 ........ ]    │ 오늘 일정        │
│ 할 일 목록    │                               │ 빈 시간에 할 일   │
│ 화면에 띄우기 │   일 · 주 · 월 캘린더           │ 브리핑           │
│ 단축키 · 설정 │                               │ (누르면 상세)     │
└──────────────┴───────────────────────────────┴─────────────────┘
```

| 영역 | 하는 일 |
|---|---|
| 사이드바 | 미니 달력으로 날짜 이동, 할 일을 마감별(마감 지남 / 오늘 / 내일 / 이번 주 / 나중 / 날짜 없음)로 보고 바로 체크·추가. 접을 수 있음 |
| 가운데 | 한 줄 입력·회의 메모 입력, 일·주·월 캘린더 |
| 오늘 패널 | 다음 일정까지 남은 시간, 빈 시간이 끼워진 오늘 일정, 추천 할 일, 브리핑. 접을 수 있음 |
| 사이드 피크 | 일정·할 일을 누르면 오늘 패널 자리에 상세가 열리고, 고치면 바로 저장. 월간에서 날짜를 누르면 그날 목록과 추가 칸이 열림 |
| 명령 메뉴 | Ctrl/⌘+K로 열어 문장으로 바로 추가하거나, 일정을 찾거나, 화면 명령 실행 |

화면이 좁으면(1100px 이하) 오늘 패널이, 휴대폰(760px 이하)에서는 사이드바도 서랍처럼 열립니다.

## 화면 위에 떠 있는 위젯

사이드바의 **화면에 띄우기**(또는 P 키)를 누르면 작은 창이 열려 **다른 프로그램 위에도 항상 떠 있습니다.**

- 다음 일정까지 남은 시간, 오늘 남은 일정, 오늘·마감 지난 할 일(체크 가능), 한 줄 추가
- 접기 버튼을 누르면 "다음 14:20 운영체제 수업 · 1시간 10분" 한 줄 막대로 줄어들고, 다시 누르면 펼쳐집니다. 닫기 버튼으로 숨깁니다.
- 본 화면과 위젯은 실시간으로 같은 내용을 보여 줍니다.

브라우저의 Document Picture-in-Picture 기능을 쓰기 때문에 다음 제한이 있습니다.

- 데스크톱 Chrome·Edge 116 이상(Opera 102 이상, Firefox 151 이상)에서 동작합니다. Safari와 휴대폰 브라우저에서는 안내 창이 뜹니다.
- 툭 탭을 닫거나 새로고침하면 위젯도 함께 닫힙니다. 툭 탭은 열어 두고 다른 창으로 이동하세요.
- 창 위치는 브라우저가 정하고, 끌어서 원하는 곳으로 옮길 수 있습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 한 줄 빠른 입력 | `다음 주 화요일 3시 교수님 면담, 그 전에 자료 정리`처럼 말하듯 쓰면 일정 1개와 할 일 1개로 나눠 줍니다. 추가 전에 미리보기에서 종류·제목·시간을 고칠 수 있습니다. |
| 회의 메모 → 할 일 | 회의 메모를 붙여 넣으면 할 일과 다음 일정만 뽑습니다. `준혁: API 문서 정리`처럼 다른 사람이 맡은 일은 체크를 풀어 둡니다. |
| 일·주·월 캘린더 | 주간은 시간표에 일정 블록, 겹치는 일정은 나란히, 현재 시각선, 요일별 바쁨, 종일·마감 줄, 1시간 이상 빈 시간 점선. 빈 칸을 누르면 그 시간에 추가 |
| 반복 일정 | `매주 월요일 10시 팀 회의`, `격주 목요일 3시 미팅`, `평일 9시 스탠드업`, `매주 화목 2시-4시 수업 12월 15일까지` |
| 겹침 경고 | 추가하기 전에 같은 시간에 잡힌 일정을 알려 줌 (반복 회차 포함) |
| 끌어서 옮기기 | 주간에서는 날짜와 시간(15분 단위), 월간에서는 날짜를 바꿈. 휴대폰은 길게 눌러서 끌기 |
| 공휴일 | 2026–2027년 공휴일과 대체공휴일 표시 |
| 오늘 브리핑 | 남은 일정, 마감, 쓸 만한 빈 시간을 2~3문장으로 요약 (AI 연결 시 AI가 작성) |

## AI 연결 (선택)

AI 없이도 **규칙 기반 한국어 파서**로 모든 기능이 동작합니다. AI를 연결하면 더 자유로운 문장과 복잡한 회의 메모도 이해합니다.

1. 사이드바 아래 **설정**을 누릅니다.
2. AI 서비스로 Google Gemini 또는 Anthropic Claude를 고르고 API 키를 붙여 넣습니다.
3. **연결 확인**으로 동작을 확인한 뒤 저장합니다.

API 키는 사용하는 브라우저의 localStorage에만 저장되고, 이 저장소나 다른 서버로 올라가지 않습니다. AI 호출이 실패하면 자동으로 규칙 기반 파서로 대신 정리합니다.

## 규칙 기반 파서가 알아듣는 표현

- 날짜: 오늘, 내일, 모레, 글피, ○요일, 목욜, 이번 주/다음 주/다다음 주 ○요일, 주말, ○월 ○일, 10/20, ○일 뒤, ○주 뒤
- 시간: 3시, 3시 반, 3시 20분, 14:30, 오전/오후/아침/점심/저녁/밤, 세시·여섯시 같은 한글 숫자, 정오
- 범위·길이: 10시부터 12시까지, 2시-3시, 1시간, 1시간 반
- 관계: "그 전에"는 앞 일정 시작을 마감으로, "끝나고"는 그날 안으로
- 반복: 매주, 격주, 매일, 평일(마다), 매주 월수금, ○월 ○일까지 / ○월까지
- 오전/오후 없이 1~7시는 오후로 봅니다.

## 실행과 테스트

설치나 빌드가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다.

```bash
node tests/parser.test.js
node tests/calendar.test.js
```

파서는 예시 문장 15개와 회의 메모 1개, 캘린더는 주·달 계산, 반복 회차, 겹침, 반복 문장 파싱, 공휴일 23개를 확인합니다.

## 만든 방법

인공지능 프로그래밍 수업의 바이브 코딩 과제로, AI와 대화하며 만들었습니다. PRD와 Todo 리스트를 먼저 작성하고, Todo 항목 하나를 끝낼 때마다 체크하고 커밋·push했습니다. 커밋 기록에서 진행 순서를 확인할 수 있습니다.

1. **1차**: 한 줄 입력, 회의 메모 추출, 지금/다음 화면
2. **2차**: 써 보니 다음 주에 미리 잡아 둔 일정을 한눈에 못 봐서, 캘린더 앱을 조사하고 주간·월간 캘린더, 반복 일정, 겹침 경고, 끌어서 옮기기를 추가
3. **3차**: 화면을 계속 오가야 하고 다른 프로그램을 쓰는 중엔 오늘 일정을 못 봐서, 노션식 한 화면 구성과 화면 위에 떠 있는 위젯을 조사하고 추가
