# 3차 조사 — 한 화면 구성과 화면 위에 떠 있는 위젯

- 작성일: 2026-10-09
- 계기: 2차 버전을 써 보니 "오늘 / 주 / 월"을 오가야 해서 불편했다. 노션처럼 한 화면에서 다 보고 싶고, 오늘 일정과 할 일은 다른 일을 하면서도 계속 보고 싶다는 요청.

## 1. 요구 정리

| 요구 | 해석 |
|---|---|
| 한 화면에 다 넣기 | 화면 전환 없이 입력, 캘린더, 오늘 할 일, 상세 보기가 동시에 보여야 한다 |
| 노션 같은 느낌 | 왼쪽 사이드바 + 넓은 본문 + 옆에서 열리는 상세(사이드 피크), 단축키와 명령 메뉴 |
| 사용하기 편하게 | 자주 쓰는 동작(추가, 오늘 확인, 완료 체크)은 클릭 한 번이나 단축키 하나로 |
| 다른 화면에서도 보기 | 브라우저 밖, 다른 프로그램 위에도 떠 있는 작은 창 |
| 감출 수 있게 | 작게 접거나 닫을 수 있어야 한다 |

## 2. 참고한 화면 구성

### Notion Calendar
- 왼쪽 사이드바에 캘린더 목록, 가운데에 일·주·월 보기, 오른쪽에 선택한 일정의 상세 패널이 있다.
- D / W / M으로 보기 전환, T로 오늘, 숫자키로 보이는 날 수를 바꾼다.
- Cmd+K 명령 메뉴로 거의 모든 동작을 키보드로 한다.
- 메뉴 막대 앱이 다음 일정을 항상 보여 주고, 누르면 하루 일정을 펼친다. → **"다른 화면에서도 보기"와 같은 아이디어**

### Notion 페이지 열기 방식 (Peek)
- 사이드 피크: 지금 화면 옆에 열어서 보던 곳을 잃지 않는다.
- 센터 피크: 가운데 겹쳐서 집중해서 본다.
- 전체 페이지: 화면 전체로 연다.
→ 일정 상세는 모달 대신 **오른쪽 사이드 피크**로 열어 캘린더를 가리지 않게 한다.

### 사이드바 설계 (UX Movement)
- 사이드바는 본문 폭을 줄이므로 **한 번에 접을 수 있어야** 한다.
- 접으면 캘린더 같은 넓은 내용을 더 많이 볼 수 있다.

## 3. "화면 위에 떠 있는 위젯"이 가능한가

웹페이지는 원래 자기 탭 안에만 그릴 수 있다. 하지만 **Document Picture-in-Picture API**를 쓰면 웹페이지가 작은 창을 만들어 **다른 모든 창 위에 항상 떠 있게** 할 수 있다.

| 항목 | 내용 |
|---|---|
| 지원 브라우저 | 데스크톱 Chrome·Edge 116 이상, Opera 102 이상, Firefox 151 이상 |
| 미지원 | Safari, 모든 모바일 브라우저 |
| 항상 위 | 다른 창 위에 떠 있다 (영상 PiP와 같은 방식) |
| 여는 조건 | 사용자가 버튼을 눌러야 열린다 (자동으로 열 수 없음) |
| 크기 | 처음 크기를 정할 수 있고, Chrome 121부터 버튼을 눌렀을 때 크기 변경 가능 → **접기/펴기 구현 가능** |
| 위치 | 브라우저가 정하고, 사용자가 끌어서 옮긴다 (코드로 위치 지정은 불가) |
| 수명 | 연 탭을 닫거나 새로고침하면 같이 닫힌다 → 툭 탭은 열어 둬야 한다 |
| 개수 | 브라우저 전체에서 한 번에 하나 |
| 내용 | 빈 창으로 시작하므로 스타일을 복사해 넣어야 한다. 같은 페이지의 코드가 창 내용을 직접 그리고 갱신할 수 있다 |

다른 방법과 비교:

| 방법 | 다른 프로그램 위에 떠 있음 | 설치 | 판단 |
|---|---|---|---|
| Document PiP | O | 필요 없음 | **채택** |
| 크롬 확장 사이드 패널 | 크롬 안에서만 | 확장 설치 | 브라우저 밖에서 안 보임 |
| PWA(앱으로 설치) | X (일반 창) | 설치 | 항상 위가 안 됨 |
| Electron 데스크톱 앱 | O | 설치·빌드 필요 | 과제 범위·기간에 비해 큼 |

결론: **Chrome/Edge에서 "화면에 띄우기" 버튼 → 항상 위에 떠 있는 미니 위젯**. 지원하지 않는 브라우저에서는 이유와 방법을 안내한다.

## 4. 툭 플래너 3차 구성

```
┌ 사이드바 ─────┬ 가운데 ───────────────────────┬ 오른쪽 패널 ─────┐
│ 툭     «      │ 10월 2주차  ‹ ›  오늘  [일|주|월] │ 지금 / 다음 카운트다운│
│ 🔍 검색·추가 ⌘K│ [ 툭 던져 두세요 ............ ] │ 오늘 일정 순서대로   │
│ 미니 달력      │                                 │ 빈 시간 · 추천 할 일 │
│ 할 일          │   주간 / 월간 / 일간 캘린더      │ 브리핑              │
│  마감 지남     │                                 │ ── 일정을 누르면 ── │
│  오늘 · 이번 주│                                 │ 여기서 상세 수정     │
│ 화면에 띄우기  │                                 │                    │
│ 설정           │                                 │                    │
└───────────────┴─────────────────────────────────┴──────────────────┘
```

- **사이드바**: 미니 달력(날짜 이동), 할 일 목록(마감 지남 / 오늘 / 이번 주 / 나중 / 날짜 없음), 위젯 버튼, 설정. 접기 가능.
- **가운데**: 입력창은 항상 위, 아래에 일·주·월 캘린더. 기본은 주간.
- **오른쪽 패널**: 1차의 "오늘" 화면 내용을 세로로 압축. 일정·할 일을 누르면 같은 자리에 상세(사이드 피크)가 열린다. 접기 가능.
- **명령 메뉴 (Ctrl/⌘+K)**: 문장을 쓰면 바로 추가 미리보기, 기존 일정·할 일 검색.
- **단축키**: D·W·M 보기 전환, T 오늘, ←/→ 이동, N 입력창으로, [ 사이드바 접기, ] 오른쪽 패널 접기, Esc 닫기.
- **떠 있는 위젯**: 다음 일정 카운트다운, 오늘 남은 일정, 오늘 할 일 체크, 한 줄 추가. 접으면 한 줄 막대("다음 14:20 운영체제 · 1시간 10분")만 남는다.
- **좁은 화면**: 1100px 아래는 오른쪽 패널을 버튼으로 여닫고, 760px 아래는 사이드바도 서랍처럼 열린다.
